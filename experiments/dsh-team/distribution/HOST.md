# 无域名异地试用 · 发起人说明

朋友只需要 Friends 安装包。这个 Host 包由团队发起人保留。

本次已验证安装、卸载与本机同步；公网连接因当前网络下载隧道工具超时，尚未实测通过。请先启动并确认服务可连接，再邀请朋友。

1. 先按「朋友试用说明」安装插件。
2. 双击 **Start-Shared-Team.command**。首次启动会从 Cloudflare 官方 GitHub 下载 cloudflared，核对 SHA-256；后续使用本机缓存。也支持已经通过 Homebrew 安装的 cloudflared。
3. 等待终端显示「团队服务地址」和「创建口令」。在 dsh → 团队情况 → 创建项目 → **连接共享服务** 中填写这两项，再创建项目。
4. 点击 **邀请成员**，将完整邀请信息和 **Team-Harness-Friends-0.0.3.zip** 发给朋友。创建口令由你保留。

新团队仅包含创建人，没有预置任务、进展或示例决定。共享服务只接收本人确认分享的进展和关键决定，不接收 dsh 的个人会话或模型密钥。完整步骤、重启与常见问题见同目录的「完整使用指南.md」。

保持这个终端窗口和电脑运行；按 Control+C 停止。Cloudflare 提供临时 HTTPS 地址，不需要账号或域名。每次重新创建隧道时地址会变，在所有成员插件的 **连接设置** 中更新地址即可。团队数据保存在本机，不会随临时地址变化而清空。

共享记录默认保存在 `~/.dsh/team-harness-shared/team.json`，创建口令及连接信息保存在同目录的本机文件中。不要将这个数据目录发给朋友。备份时请将该目录作为敏感团队数据保存。

临时连接适合几个人的短期试用，网络不可达时会无法同步，没有在线保证。若下载或连接失败，终端会报错；可先运行 `brew install cloudflared` 后重试。正式长期运行可将同一服务迁到云服务器。

官方说明：[Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)。
