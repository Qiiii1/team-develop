# 团队 Develop · 后端与前端协作

本机部署、局域网访问的团队 AI 空间，每位成员使用自己的 API Key。当前后端版本 **0.2.0**，本分支为 **`backend`**，提供可运行的后端、参考前端和接口文档。

## 快速启动

需要 Node.js `>=22.9.0` 和 npm。新获取项目：

```sh
git clone --branch backend https://github.com/Qiiii1/team-develop.git team-develop-api
cd team-develop-api
npm ci
npm start
```

已有项目则在项目根目录运行 `npm start`。启动会编译 TypeScript、创建本机数据库并执行尚未应用的迁移，保持终端窗口打开；停止按 `Control + C`。

- 默认仅本机访问：`http://localhost:4185/`。
- 管理入口：同一服务地址下的 `/admin`。
- 健康检查：`GET /health`，返回 `{"ok":true}`。
- 已配置 HTTPS 的电脑使用 `https://localhost:4185/`，**以终端打印的地址为准**。

首次使用先注册账号（密码至少 8 位），创建团队，再生成邀请码让另一个账号加入。没有默认账号、默认密码或预置共享 Key。每人在「我的 AI 配置」保存自己的 DeepSeek 模型与 Key，保存不会调用模型；发问时才验证真实 Key 和额度。

系统管理员由部署者为已有账号授权，在项目根目录执行：

```sh
npm run admin:grant -- 你的登录名
```

完成后刷新网页即可。普通注册账号、团队发起人和团队管理员不会自动成为系统管理员。

## 已实现功能

- 注册、登录、退出、7 天会话、账号与团队权限隔离。
- 团队创建、邀请加入、邀请过期／撤销／次数限制、成员权限与移除。
- 每人独立的 DeepSeek 配置，API Key 加密存储，不回显。
- 默认私密的个人 AI 对话，团队公共讨论与显式 `@AI`；公共调用使用发送者自己的 Key。
- 编辑、预览并由本人确认的文字成果分享。
- 团队背景和决定草案、指定成员确认、历史版本与冲突检查。
- 对话固定资料包版本，资料更新后由本人选择采用新版，旧依据分享需复核。
- 系统管理后台：概览、搜索与分页、启停账号、强制退出、团队管理、成员管理、操作记录。

当前模型回答非流式，讨论采用轮询。文件上传／解析、WebSocket、自动催办、发起人转让和密码重置尚未实现。

## 前后端怎样协作

后端主要维护 `backend/`、数据库迁移、相关依赖和接口文档，提交到 `backend`。前端在自己的分支开发页面和交互，通过 `/api/v1` 接口连接服务；现有 `web/` 是已经对接的参考实现。

`frontend` 分支此前已清空，前端开发者需提交自己的项目。建议在独立目录克隆 `backend` 作为本地联调服务，各自使用本机数据库和 Key。先接通「注册 → 登录 → 获取团队列表」，再接配置、讨论和个人 AI；具体配置见[前端联调指南](docs/前端联调.md)。接口参数、返回或权限变化时，同一次提交更新 [API 文档](docs/API.md)。

推送代码不会自动运行后端。合并到 `main` 前应检查实际文件差异，避免用空分支或整份目录覆盖已有后端。网站登录会话和模型 API Key 分开处理，模型调用始终由后端完成。

## 开发和验证

在仓库根目录运行：

```sh
npm run dev:web       # 后端开发模式，监听代码变更
npm run check         # 类型与 JS 语法检查
npm test              # 后端集成测试和旧原型回归
npm run test:browser  # 浏览器测试，使用本机已安装的 Google Chrome
```

后端测试使用隔离数据库与模拟模型，不消耗真实模型额度。已有双账号浏览器测试覆盖登录、团队、协作、后台管理、HTTPS 和独立静态前端对接；真实 Key 与两台设备间的网络／证书仍需实际验证。

## 本机配置与数据

可按需复制 `.env.web.example` 为 `.env.web.local` 后修改，服务启动时读取该文件。不要覆盖已有配置。

| 默认路径 | 内容 |
| --- | --- |
| `.local/web/team.db` | SQLite 数据库，账号、团队、聊天、成果、资料版本等 |
| `.local/web/secrets/master.key` | 个人 API Key 的加密主密钥 |
| `.env.web.local` | 本机监听、证书、允许来源等配置 |

数据库、备份、真实环境文件、API Key、会话／邀请令牌、证书私钥与加密主密钥不提交到 GitHub。恢复模型配置需要数据库与原主密钥；停止服务后再复制备份，运行中应使用 SQLite backup 接口。

局域网使用 `npm run setup:lan -- 本机内网IP` 生成证书和配置，详见[局域网 HTTPS 配置](docs/局域网HTTPS配置.md)。队友需在同一可互访网络并信任公开 CA，使用终端打印的 LAN 地址。电脑关闭、休眠或服务停止时无法访问。

[GitHub Pages 预览](https://qiiii1.github.io/team-develop-web/)目前仅是静态预览，业务请求关闭，没有启用公网转发。相关背景见 [Pages 与本机后端](docs/GitHubPages与本机后端.md)。
