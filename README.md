## 网页版第一阶段

[GitHub Pages 网页预览](https://qiiii1.github.io/team-develop-web/)已发布，当前尚未连接本机 API。前后端分离和跨域登录适配已完成，已按用户选择关闭公网转发，当前保留本机／局域网服务；说明见 [Pages 与本机后端](docs/GitHubPages与本机后端.md)。

已实现独立账号、登录退出、团队创建、邀请码加入、成员管理及每人独立的 API Key 配置。模型对话和成果分享尚未接入，保存 Key 不调用模型。

推荐 Node.js 24 LTS。首次运行：

```sh
npm ci
npm start
```

打开 http://localhost:4185 。首次使用注册自己的账号，创建空团队，再生成邀请码。用无痕窗口或另一个浏览器注册第二个账号，输入邀请码加入，可在一台电脑上先验证多人流程。

个人模型配置位于「我的 AI 配置」，每位成员独立保存。数据库保存在 `.local/web/team.db`，加密主密钥默认位于 `.local/web/secrets/master.key`；恢复模型配置需要同时保留主密钥。旧原型数据保持独立。

同一局域网的队友访问、HTTPS 配置、接口说明与验证记录见 [第一阶段试用指南](docs/网页第一阶段试用.md)。可复制 `.env.web.example` 为 `.env.web.local` 设置运行参数，默认不读取旧单人原型的共享 Key。

独立的[系统管理后台](docs/系统管理后台.md)位于 `/admin`，可统一管理账号、团队与成员，并查看操作记录。部署者通过 `npm run admin:grant -- 登录名` 授予系统管理员权限，新注册账号默认无此权限。

需要局域网访问时，按[局域网 HTTPS 配置](docs/局域网HTTPS配置.md)执行 `npm run setup:lan -- 本机内网IP` 生成证书和配置。成员首次需要信任脚本生成的公开 CA 证书 `artifacts/Team-Develop-LAN-CA.crt`。本机数据、证书、密钥、截图和打包产物不包含在源码仓库中。

```sh
npm run dev:web       # 后端开发模式
npm run check        # 类型和语法检查
npm test             # 新后端及旧原型回归
npm run test:browser # 使用已安装的 Google Chrome 验证双账号与手机布局
```

单人试用的 AI 项目空间。首页以项目对话为中心，从侧栏“团队情况”进入几何工位与进度视图。一个从空白开始的可编辑项目，保留模拟成员、手动任务管理、真实 DeepSeek 对话和人工确认的项目结论。页面采用白色、浅灰与蓝色强调的简洁风格。

## 启动

需要 Node.js 22.9 或更高版本。旧原型本身没有第三方依赖。

```sh
npm run start:legacy
```

打开 http://localhost:4173 。默认没有内置任务或结论，先设置项目目标、创建自己的第一项任务。数据保存在 `.local/project.json`，刷新和重启不会清空。

## 连接真实 AI

点击侧栏底部的“DeepSeek”，或空白对话页中的“连接 DeepSeek”。输入 API Key，点击“保存并启用”即可立即生效，无需重启服务。“高级设置”可以修改模型名称和接口地址；再次打开时 Key 不回显，留空会保留已保存的 Key。窄屏的连接入口位于顶部。

配置保存在本机的 `.local/ai-config.json`，文件权限为 0600，不会被提交到 Git，也不会随项目数据或网页状态返回。保存配置不会向模型发送请求，Key 的有效性将在发起对话时验证。

也支持通过 `.env.local` 提供初始配置；如果尚未通过窗口保存配置，服务会读取下面的变量：

```dotenv
DEEPSEEK_API_KEY=你的Key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
PORT=4173
```

环境变量的修改需要重启 `npm start`；窗口保存的配置优先生效。基础版不需要 Supabase 或部署账户。

AI 使用 DeepSeek Chat Completions 接口，参考当前项目目标、成员角色、任务、最近 24 条成功对话和最多 40 条最近确认结论。它只回复建议，没有修改任务或结论的工具；所有修改都由用户在界面中确认。模拟成员不是实际用户，界面和 AI 都明确区分。

## 操作

- 项目设置：点击侧栏的项目名称或输入框下方“项目背景”，编辑名称、目标和简介。
- 项目对话：自由对话或点击快捷问题。Enter 发送，Shift + Enter 换行；页面切换会保留未发送的草稿。
- 团队情况：点击工位查看成员任务；编辑姓名和角色，添加模拟成员；右侧展示整体进度，点击管家工位返回对话。
- 项目任务：创建、编辑、删除，指定负责人、状态、可选期限和成果链接；按状态或负责人筛选。
- 关键结论：手动记录，或从聊天消息确认保存；可以编辑、删除和回看消息来源。

## 验证

```sh
npm run check
npm test
```

测试使用隔离数据和本地模拟接口验证请求契约，不消耗真实模型额度。真实 DeepSeek 的连通性需要用户配置有效 Key 后验证。

这是本机单人原型，服务仅监听 127.0.0.1。多人登录、真实同步、云端部署、主动介入和工具执行属于后续版本。
