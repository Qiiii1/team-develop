# 新前端与团队后端的本机整合预览

整合分支：`codex/frontend-backend-preview`。后端基于 `bca424d`，新前端基于 `frontend` 的 `3e8c3b0`。前端原分支曾清空后重新提交，所以保留后端目录，将前端完整放入 `frontend/`，再记录合并关系，避免应用其删除后端文件的历史。

在仓库根目录执行 `npm start`。首页使用新版前端，`/admin` 是原系统管理后台，`/classic` 保留完整核心协作页面。已有 HTTPS 配置继续生效；以终端输出的本机／LAN 地址为准。

## 已接入的真实功能

- 注册／登录／退出使用 `/api/v1/auth/*` 的账号和 HttpOnly 会话，密码至少 8 位。
- 新建／历史项目对应后端真实团队，不再创建演示项目编号。
- 邀请通过后端邀请码，接收者登录后明确确认加入；工位显示真实团队成员及头像。
- 个人姓名与头像通过新增 `PATCH /api/v1/me/profile` 保存；请求体 `{displayName,avatarId}`，头像为 `ip-1` 至 `ip-9`，响应 `{user}`。
- 个人 AI 配置通过原有加密配置接口保存，不运行前端原型的明文 Key 文件服务。
- 用户点击「检查连接」才调用新增 `POST /api/v1/me/ai-config/test`；请求 `{model,apiKey?}`，可用本人的已保存 Key，响应 `{ok:true}`。草稿 Key 不保存，失败不回显提供方任意错误内容；该操作会产生模型调用。
- 个人 AI 页面使用本人 thread 与消息接口，刷新后可恢复历史，其他人不可读取。支持编辑最近回答并明确确认分享到团队。
- 网站同源部署，写操作沿用 CSRF、成员资格、团队停用和现有权限检查。

`GET /me`、注册／登录和团队成员列表额外返回 `avatarId`，原字段保持兼容。迁移 `0003` 只增加带默认值的头像列，保留原账号、团队、聊天及 Key。

## 仍是前端本地原型的部分

新版工作台任务、知识库文件、黑板和举手讨论尚未映射为多人共享的后端业务表，页面已提示仅保存在当前浏览器。浏览器原型状态与 IndexedDB 文件按登录用户隔离；不会把一个成员的私人对话拷贝到公共数据。

文件摘要接口暂未接入，不运行前端附带的单人资料解析／明文密钥服务。附件不会被当作已经提供给 AI 的上下文；个人 AI 使用后端真实资料包。需要现有公共讨论、资料确认与版本管理时，打开 `/classic` 的核心协作入口。

场景固定显示五个成员工位和一个 AI 工位；超过五人的团队仍可使用后端，场景扩展尚未实现。

## 验证

`npm run check`、`npm run test:web`；`npx playwright test backend/test-ui/frontend.spec.ts` 验证双账号注册、创建／加入团队、保存个人配置、真实私人接口对话与页面切换。模型调用在测试中使用模拟提供方，不消耗真实额度。

网页只开放明确列出的 HTML、JS、CSS 与素材路径；前端 Node 服务、解析脚本、JSON 状态文件和仓库源码没有挂载到网站。内联脚本使用 CSP 哈希，未全局放开任意内联 JavaScript。
