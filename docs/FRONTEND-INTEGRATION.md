# main 前后端整合版

本分支在现有 backend 和 main 历史上接入 frontend 页面；不修改远端 frontend 分支。

## 启动

要求 Node.js 24；首次执行 `npm ci`，然后 `npm start`。默认访问 http://127.0.0.1:4185 。原独立前端预览端口 4178 不受影响。
资料提取另需 Python 3 和 `python -m pip install --target frontend/.runtime -r frontend/requirements.txt`。
默认由同一个 Fastify 服务提供页面与 `/api/v1` 接口，不需要跨域配置。旧后端参考界面可使用 `HARNESS_WEB_FRONTEND=0` 启动；管理入口仍为 `/admin`。

## 已接入

- 正式注册、登录、会话恢复、退出登录；注册同时选择人物、填写显示姓名和个人 DeepSeek API 配置
- 创建/选择团队项目，管理员生成真实邀请链接；新成员注册或已有账号登录后加入项目
- API 配置按后端登录用户隔离并加密保存；浏览器不保存 API Key，后端固定调用官方 DeepSeek 接口
- 个人 AI 新建对话、发送消息、历史恢复、私人对话隔离、分页加载旧消息；错误不会伪造回答，重复发送同一请求编号不会重复调用模型
- 资料摘要复用原文件提取器，走登录鉴权与 CSRF 校验，调用当前用户的模型配置
- 保留共同侧边栏和邀请/举手组件；页面切换不重新建立侧边栏

## 暂时的边界

- 工作台任务、阶段、验收、黑板问题卡片、知识库文件仍使用原来的本地存储；并非多人共享或后端权限控制
- 首页座位由真实成员加入顺序派生，现有场景最多显示五个人类座位；当前后端没有永久座位或头像字段，头像选择仍限当前浏览器
- 后端暂无修改昵称接口，账户页以真实账号姓名只读展示
- 后端公共讨论、分享、确认版本与当前黑板/文件库的数据语义不同，本次未强行替换现有界面
- 个人 AI 暂不发送本地文件引用；后端文件库接口接入后才能保证模型读取实际文件
- 保存 API 配置不等于验证额度或模型可用性；只有用户主动发送消息/提取资料才调用模型
- `.local/` 数据库和加密主密钥需要一起备份，不进入 Git；请勿把本地配置、数据库或真实密钥提交到仓库

## 验证

`npm run check:web`、`npm test`、`npx playwright test`。
新增 product.spec.ts 使用临时数据库和模拟模型，覆盖正式页面开户、邀请、账号隔离、聊天历史、资料摘要与退出，不消耗真实 API 额度。
