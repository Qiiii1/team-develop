# 历史单人网页原型

本文仅适用于 `npm run start:legacy` 启动的 4173 端口原型。当前多人版见[仓库 README](../README.md)。


内部产品讨论单独保留，不随源码仓库发布；下文介绍历史原型的已实现能力。

单人试用的 AI 项目空间。首页以项目对话为中心，从侧栏“团队情况”进入几何工位与进度视图。一个从空白开始的可编辑项目，保留模拟成员、手动任务管理、真实 DeepSeek 对话和人工确认的项目结论。页面采用白色、浅灰与蓝色强调的简洁风格。

## 启动

需要 Node.js 22.9 或更高版本。旧原型本身没有第三方依赖。

```sh
npm run start:legacy
```

打开 http://localhost:4173 。默认没有内置任务或结论，先设置项目目标、创建自己的第一项任务。数据保存在 `.local/project.json`，刷新和重启不会清空。

## 连接真实 AI

点击侧栏底部的“DeepSeek”，或空白对话页中的“连接 DeepSeek”。输入 API Key，点击“保存并启用”即可立即生效，无需重启服务。“高级设置”可以修改模型名称和接口地址；再次打开时 Key 不回显，留空会保留已保存的 Key。窄屏的连接入口位于顶部。

配置保存在本机的 `.local/ai-config.json`，文件权限为 0600，不会被提交到 Git，也不会随项目数据或网页状态返回。保存配置不会向模型发送请求，Key 的有效性将在发起对话时验证。

也支持通过 `.env.local` 提供初始配置；如果尚未通过窗口保存配置，服务会读取下面的变量：

```dotenv
DEEPSEEK_API_KEY=你的Key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
PORT=4173
```

环境变量的修改需要重启 `npm run start:legacy`；窗口保存的配置优先生效。基础版不需要 Supabase 或部署账户。

AI 使用 DeepSeek Chat Completions 接口，参考当前项目目标、成员角色、任务、最近 24 条成功对话和最多 40 条最近确认结论。它只回复建议，没有修改任务或结论的工具；所有修改都由用户在界面中确认。模拟成员不是实际用户，界面和 AI 都明确区分。

## 操作

- 项目设置：点击侧栏的项目名称或输入框下方“项目背景”，编辑名称、目标和简介。
- 项目对话：自由对话或点击快捷问题。Enter 发送，Shift + Enter 换行；页面切换会保留未发送的草稿。
- 团队情况：点击工位查看成员任务；编辑姓名和角色，添加模拟成员；右侧展示整体进度，点击管家工位返回对话。
- 项目任务：创建、编辑、删除，指定负责人、状态、可选期限和成果链接；按状态或负责人筛选。
- 关键结论：手动记录，或从聊天消息确认保存；可以编辑、删除和回看消息来源。

## 验证

```sh
npm run check
npm test
```

测试使用隔离数据和本地模拟接口验证请求契约，不消耗真实模型额度。真实 DeepSeek 的连通性需要用户配置有效 Key 后验证。

这是本机单人原型，服务仅监听 127.0.0.1。多人登录、真实同步、云端部署、主动介入和工具执行属于后续版本。
