# 个人 AI 自动总结与团队摘要

2026-11-04。状态：已确认的新需求，尚未实现；不代表当前 0.2.0 已具备此功能。

## 已确认的规则

- 个人记录由该成员自己的 AI 负责总结，沿用本人的模型配置与 API Key。
- 自动触发有两个条件，满足任意一个即可：未总结的对话达到设定轮数，或连续半小时未使用个人 AI。
- 总结完成后自动保存到总数据库的团队摘要区，团队成员及其 AI 可以读取；这条自动总结路径无需每次预览、点击确认。
- 原始私人对话继续按本人权限隔离，不因摘要自动发布而向团队开放。
- 自动摘要属于成员工作记录和参考资料，不直接变成生效的团队背景或决定；正式决定仍走指定成员确认流程。

## 触发口径与执行方式

下列为实施口径，轮数阈值的具体数值尚未确定。

| 条件 | 执行口径 |
| --- | --- |
| 达到轮数 | 每段私人对话分别统计自上次总结后新增的完整问答。一轮为一次用户提问及对应的成功 AI 回答；失败、重放与自动总结请求不计入轮数。阈值 N 做成可配置项。 |
| 空闲 30 分钟 | 按成员最后一次个人 AI 交互结束后的空闲时间计算。新的个人 AI 请求会重新计算空闲时间；仍有请求运行时不执行空闲总结。达到 30 分钟后，对该成员有未总结内容的私人对话分别生成摘要。 |
| 没有增量 | 不创建任务，不重复总结或调用模型；总结本身不重置用户使用时间。 |

计时和调度由后端负责，浏览器不承担计时任务。服务运行时，即使成员关闭网页，也可执行空闲总结；部署电脑关机、休眠或服务停止时无法执行，恢复后检查尚未完成的工作。空闲到期后由后台扫描发现并排队执行，不承诺精确到秒完成。

个人 AI 指使用本人的配置执行一次独立的总结请求，不需要为每位成员常驻一个模型进程，也不依赖聊天模型自行记忆或设置计时器。后台总结让位于成员正在进行的交互，避免占用本人已有的单请求并发名额。

## 数据流

私人对话新增记录 → 后端检测轮数或空闲条件 → 固定本次来源范围 → 个人 AI 生成结构化摘要 → 校验并保存到团队摘要区 → 团队成员读取，或后端选入有权限的模型上下文。

当前私人原文已经保存在部署电脑上的数据库里，因此这里的“上传”在现有架构中，是将生成的摘要另行写入同一总数据库的团队可读数据区。以后更换部署位置，不改变这条权限规则。

摘要进入团队可读数据区，不代表每次提问都把所有摘要发给模型。首步可接入现有团队资料包，保留版本与已有对话主动采用新版的机制；基于问题的相关性检索另行实施。

## 摘要内容与来源

摘要应包括标题、工作目标、本阶段完成内容、结论及理由、尝试过的方案、待解决问题、下一步工作，并记录作者、团队、对话标识、覆盖时间、来源消息范围、所依据的团队资料版本与生成时间。

个人想法、假设、AI 建议和团队已确认的决定要明确区分。摘要可以归纳本人贡献，不替未参与该段对话的成员推断贡献。团队读者获得摘要与来源元数据；来源标识不会赋予其读取私人原文的权限。

总结采用增量范围：首次覆盖尚未总结的记录，后续覆盖新记录，必要时参考已有摘要。原文保留，已发布摘要保留各自来源范围，不能仅按最近 20 条聊天截取而漏掉尚未总结的早期记录。过长输入需分段处理。

## 保存与任务状态

实施时增加以下数据职责，具体表结构通过新迁移交付：

| 数据 | 职责 |
| --- | --- |
| 总结进度 | 记录成员、团队、私人对话、已总结到的消息位置及个人 AI 活动时间。 |
| 总结任务 | 记录固定来源范围、触发原因、模型、待执行／运行中／成功／失败或结果未知状态及用量。 |
| 团队摘要 | 保存生成内容、作者、来源范围、资料依据和生成时间，并按团队隔离读取。 |

两个触发条件同时满足时合并为一个任务。同一来源范围不得重复发布；只有摘要成功保存，才能在同一事务中推进总结进度。生成期间出现的新消息保留为下一次增量，不被本次进度跳过。

总结请求会使用本人的模型额度，产品配置中应说明自动调用与摘要可见范围。无 Key、账号或团队停用、成员被移除时不继续自动调用或发布；调用开始前及落库前都校验当前身份与团队资格。后台使用独立任务身份与权限检查，不依赖浏览器会话持续有效。

失败时保留原文与未总结范围，不标记成功。超时、断网或进程中断导致结果未知时，不自动重放可能已经计费的请求；展示失败状态，重试策略明确区分未发出的任务和可能已执行的请求。

## 与当前版本的衔接

当前 0.2.0 仍使用近期消息和固定资料包，没有后台自动总结任务。既有“作为分享草稿 → 预览 → 确认发布”可继续用于成员主动分享额外成果；新自动摘要入口单独实现，不伪造用户点击，也不复用为人工确认过的发布记录。

交付需要新增数据库迁移、后台调度、个人模型总结请求、摘要列表与状态展示、团队上下文接入，并验证触发、去重、关闭网页后的执行、私聊隔离、成员权限变化和中断恢复。
