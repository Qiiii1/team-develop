# 网页版第一阶段试用

更新：2026-10-31。实现范围为账号、团队、邀请、成员权限及个人模型配置。没有预置成员、共享 Key、任务或自动模型调用。

管理扩展：已增加独立的[系统管理后台](系统管理后台.md)，系统管理员可从 `/admin` 管理账号、团队与成员，操作记录保存在数据库中。

## 本机启动

在项目根目录，推荐使用 Node.js 24 LTS：

```sh
npm ci
npm start
```

访问 http://localhost:4185 。服务会编译 TypeScript、执行尚未应用的数据库迁移，并创建独立存储目录。保持终端运行；Ctrl+C 停止服务。

1. 点「注册账号」，填写显示姓名、登录名和至少 8 字符的密码。
2. 创建一个空团队，目标和背景此阶段不要求填写。
3. 点「生成邀请码」，可以设置有效期与可加入人数。原始邀请码只在生成页面显示，重新打开页面后可撤销旧邀请并生成新的。
4. 在无痕窗口或另一个浏览器中注册第二个账号，使用邀请码加入。
5. 回到发起人的窗口点「刷新成员」，确认双方看到同一份名单。
6. 双方在「我的 AI 配置」分别保存自己的 Key。已保存 Key 不回显，留空可保留原 Key，删除需要明确确认。
7. 退出后重新登录，或重启服务，检查账号、成员与配置仍在。

显示姓名可以重复，登录名不区分大小写。Key 保存成功只表示存储成功，当前阶段不检验 Key 是否有效，不产生模型调用费用。

## 同一局域网访问

正式输入真实密码与 Key 时使用 HTTPS。已有可用局域网证书时，复制 `.env.web.example` 为 `.env.web.local`，配置：

```dotenv
HARNESS_WEB_HOST=0.0.0.0
HARNESS_WEB_PORT=4185
HARNESS_TLS_CERT=/你的证书目录/cert.pem
HARNESS_TLS_KEY=/你的证书目录/key.pem
```

证书需要覆盖部署电脑的内网 IP 或使用的本地域名，并在成员设备上获得信任。然后运行 `npm start`，将终端显示的 `LAN: https://...:4185` 地址发给队友。使用自定义本地域名时设置 `HARNESS_WEB_ALLOWED_HOSTS=你的本地域名`。

只用测试账号与测试 Key 做一次临时局域网连通性验证，可以显式选择 HTTP：

```sh
HARNESS_WEB_HOST=0.0.0.0 HARNESS_ALLOW_INSECURE_LAN=1 npm run start:web
```

队友访问终端显示的 `LAN: http://...:4185`。HTTP 模式不加密传输，避免使用真实 Key、真实个人密码。服务不会修改电脑防火墙或路由器配置；需要同一可互访的网络。若网络有客户端隔离或系统拦截端口，需要调整相应设置。

默认只绑定 `127.0.0.1`，队友无法通过这个默认入口连接。局域网地址变化后重新启动服务；建议在路由器上固定部署电脑的 DHCP 地址。关闭电脑或停止服务后成员暂时无法访问。

## 权限与数据

- 注册账号不等于加入任何团队；没有成员资格就不能读取团队或成员列表。
- 发起人可授予或收回管理员权限，并移除非发起人成员；管理员可邀请和移除普通成员。
- 移除后立即失去团队访问权。重新加入需要管理员在移除后新生成的邀请。
- 邀请支持过期、撤销、次数限制；重复加入不重复计数。加入和名额消耗在同一事务中完成。
- 每人只可设置自己的 Key。通过请求提交别人的 userId 不会改变归属。
- Key 使用 AES-256-GCM 加密，主密钥不保存在数据库中；密码使用带独立盐的 scrypt 派生值。
- 部署者能够访问电脑上的数据库与主密钥，应用层成员隔离不等于对部署者端到端保密。

数据文件：

| 文件 | 用途 |
| --- | --- |
| `.local/web/team.db` | 新网页版的 SQLite 数据库 |
| `.local/web/team.db-wal` / `team.db-shm` | SQLite 工作文件，运行中由数据库管理 |
| `.local/web/secrets/master.key` | 模型 Key 加密主密钥，默认文件权限 0600 |
| `.env.web.local` | 可选启动配置 |

备份的简单方式是停止服务后复制数据库与独立主密钥，再重新启动。不要只复制运行中的 db 文件而漏掉 WAL 内容。若丢失主密钥且仍有加密配置，服务会拒绝启动，要求恢复原主密钥；不会自动生成新主密钥覆盖数据。

旧 `.local/project.json`、旧模型配置与 dsh 数据没有自动导入；旧原型使用 `npm run start:legacy`，地址仍为 http://localhost:4173 。新旧入口使用独立数据目录。
