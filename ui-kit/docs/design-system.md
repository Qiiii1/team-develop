## 断点

1160px 以下隐藏辅助面板；700px 以下导航转换为顶部横向滚动导航、展示页单列。与原型完全隐藏移动导航相比，此处保留产品页面切换入口。

## 扩展规则

1. 先检查组件库是否已有等价组件。
2. 视觉变化通过变量或显式 variant 表达，避免各页面覆盖组件内部选择器。
3. 业务逻辑放应用层，通用状态和可访问性放组件层。
4. 全局样式仅由应用重置 body；UI 包不重置宿主页面。
5. 新组件要有完整属性类型、键盘可用性、展示示例和必要的行为验证。
6. 第一版组件以参考风格为基础；系统级无障碍审计与真实设备全面适配仍需在正式上线前进行。
